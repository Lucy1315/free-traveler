## 2. 44px 터치 영역 · 2px 포커스 링

5개 화면(`/`, `/about`, `/travel-tools`, `/mates`, `/account`)의 보이는 모든 링크·버튼·입력·탭을 측정했다(체크박스·라디오는 라벨 영역을 포함해 44px를 확보하므로 제외). 포커스 링은 각 화면에서 Tab 25회 동안 포커스된 요소의 outline을 확인했다.

| 항목 | 최초 측정 | 수정 후 재측정 |
|---|---|---|
| 44px 미만 대상 | 화면마다 17~60개(헤더 메뉴 30px·아이콘 40px, 즐겨찾기 하트 36px, 푸터 링크 16px, 사진 출처 링크 15~39px 등) | 0개 |
| 2px 포커스 링 없음 | 헤더·푸터 링크(브라우저 기본 1px), 모든 입력칸·드롭다운 | 0개 |

### 발견한 결함과 조치(커밋 `3416cd0`)

1. **입력칸 포커스 링 미표시**: Tailwind v4에서 `outline-none`이 `--tw-outline-style`을 `none`으로 고정해 `focus:outline`이 적용되지 않았다. 모든 입력·드롭다운에서 `outline-none`을 제거했다(Drawer 패널 자체는 유지).
2. **헤더·푸터 링크 포커스 링 1px**: `globals.css` base 레이어에 링크·버튼·탭의 2px `focus-visible` 기본 링을 추가했다. 날짜 입력은 안쪽 칸 포커스 때 `:focus-within` 링을 그린다.
3. **44px 미만 대상**: 헤더 로고·메뉴·아이콘, 즐겨찾기 하트, 푸터 링크, "동행 찾기 전체 보기", 사진 출처 링크를 44px 이상으로 키웠다.
4. **전역 스타일 잔재**: `globals.css`의 create-next-app 기본값이 body 글꼴을 Arial로 지정해 Inter(D-001 §3)를 덮어썼고, OS 다크 모드에서 배경만 검게 바뀌었다. 제거했다.
