# MANUAL-CHECK-RESPONSIVE — 반응형 점검 체크리스트

- 대상 Task: `TASKS/TASK-MANUAL-CHECK-RESPONSIVE.md`
- 기준: `design-reference/D-001/DESIGN.md` §5(브레이크포인트·여백)·§15(Hero 뷰포트 55~65%)
- 점검일: 2026-09-19
- 환경: 로컬 프로덕션 빌드, Playwright Chromium. 폭 320·390·768·1440px(높이 800/900px). `/mates` 목록 API는 DB 미적용 상태라 빈 응답으로 대체했다.
- 방식: 각 폭·화면에서 문서 가로 넘침(`scrollWidth - clientWidth`)과 화면 밖으로 나간 요소(가로 스크롤 탭 제외)를 측정하고, 첫 화면 스크린샷을 눈으로 확인했다.

## 1. 가로 스크롤·겹침

| 폭 | `/` | `/about` | `/travel-tools` | `/mates` | `/account` |
|---|---|---|---|---|---|
| 320 | 0 | 0 | 0 | 0 | 0 |
| 390 | 0 | 0 | 0 | 0 | 0 |
| 768 | 0 | 0 | 0 | 0 | 0 |
| 1440 | 0 | 0 | 0 | 0 | 0 |

(값은 가로 넘침 px. 화면 밖으로 나간 요소는 모든 경우 0개였다.)

### 발견한 결함과 조치

1. **320px 메인 Hero 버튼 줄바꿈** — "국내 여행지 보기"가 "보 / 기"로 끊겼다. 좁은 폭에서는 버튼을 세로로 쌓고(`sm` 이상 가로), 버튼 문구는 줄바꿈하지 않게 했다.
2. **320px 계정 로그인 카드 탭 잘림** — "비밀번호 재설정" 탭이 카드 밖으로 밀려 잘려 보였다(탭 목록 267px / 가용 254px). 탭 이름을 "비밀번호 찾기"로 줄이고, 카드 안쪽 여백을 좁은 폭에서 16px로, 공용 Tabs 간격을 좁은 폭에서 16px(`sm` 이상 24px)로 조정했다. 수정 후 254px / 254px로 들어온다.

## 2. Hero 높이(뷰포트 대비)

| 화면 | 320 | 390 | 768 | 1440 | 기준 |
|---|---|---|---|---|---|
| `/` 메인 Hero | 55% | 55% | 55% | 55% | 55~65% 충족 |
| `/about` 대표 Hero | 55% | 55% | 55% | 55% | 55~65% 충족 |

`/travel-tools`·`/mates`·`/account`는 Hero 대신 Intro Section을 쓰는 화면이라 해당하지 않는다.
